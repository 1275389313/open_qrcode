# 网页二维码识别

这是一个浏览器扩展。网页上有二维码图片时，在图片上单击鼠标右键，浏览器原来的菜单里会多出一项 **识别二维码**。点它之后，扩展在你自己的电脑上认出二维码里的文字。如果内容是网址，可以打开；也可以一键复制。

它不会在页面角落放按钮，也不会换成自己的右键菜单。保存图片、复制图片这些浏览器原有的菜单项都还在。

识别库是 [jsQR](https://github.com/cozmo/jsQR) 1.4.0。扩展里已经带上了这个文件，不需要另外编译，也不会把图片上传到别的服务器。

## 安装（Chrome 或 Edge）

1. 下载这份代码。在仓库页面点 **Code**，再点 **Download ZIP**，然后解压。解压后的文件夹里要能直接看到 `manifest.json`。
2. 打开扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions`
   - Edge 地址栏输入 `edge://extensions`
3. 打开右上角的 **开发者模式**（Developer mode）。
4. 点 **加载已解压的扩展程序**（Load unpacked）。
5. 选中刚才那个含有 `manifest.json` 的文件夹，确定。

列表里出现「网页二维码识别」就装好了。浏览器可能会把它的图标收在工具栏的拼图菜单里，这不影响使用，右键菜单一样可用。

Edge 和 Chrome 的步骤相同，只是扩展页的地址不一样。

## 安装（Firefox）

支持 Firefox 128 及以上。

1. 同样先拿到含有 `manifest.json` 的文件夹。
2. 地址栏打开 `about:debugging#/runtime/this-firefox`。
3. 点 **临时载入附加组件…**（Load Temporary Add-on…）。
4. 选中文件夹里的 `manifest.json`。

这是临时安装。Firefox 完全退出后扩展会消失，下次要再载入一次。

## 怎么用

1. 打开有二维码图片的网页，等图片显示出来。
2. 在二维码图片上单击 **右键**。
3. 在浏览器原来的菜单里点 **识别二维码**。扩展比较多时，浏览器可能把它放进「扩展程序」子菜单，点进去就能看到。
4. 页面中间会显示识别到的文字。
   - 点 **复制**，把内容放到剪贴板。
   - 内容本身是 `http://` 或 `https://` 网址时，还会出现 **打开链接**。

右键普通文字时，菜单和以前一样，不会多出这一项。

也可以在视频画面上右键，用同一项识别当前这一帧。读不到画面时，会再试视频的封面图。

## 哪些情况可以识别

浏览器只允许扩展出现在「图片」和「视频」这两类系统右键菜单里，所以：

- 普通图片（`<img>`，包括指向 SVG 文件的图片）可以识别。
- 视频当前画面可以识别。
- 画布（`<canvas>`）、只用 CSS 背景画出来的图、以及直接嵌在页面里的 SVG，浏览器不会把它们当成图片菜单，因此菜单里不会出现「识别二维码」。把二维码做成一张普通图片就能识别。

## 识别不到时

- 到扩展管理页确认「网页二维码识别」已启用，然后刷新网页再试。
- 二维码要大致完整、不要太模糊。
- 一张图里如果有好几个二维码，可能只认出其中一个。
- 普通条形码不是二维码，这个扩展不识别。
- 本地打开的 `file://` 图片如果读不到，可以在扩展详情里打开「允许访问文件网址」（Allow access to file URLs）后再试。

## 隐私

只有在你点了「识别二维码」之后，扩展才会读取这一张图片，并在你的电脑上识别。图片和识别结果不会上传到本仓库或别的服务器。

安装时浏览器会提示扩展可以访问网站数据。二维码图片经常放在别的域名上，没有这个权限就读不到像素。扩展不会在你浏览时自动扫描页面。

## 以前的暴力猴脚本

`legacy/qrcode-reader.user.js` 是旧版用户脚本，只作保留。它会在页面右下角放一个按钮，并且用自己的菜单代替浏览器右键菜单。请改用上面的扩展，不要再把那个脚本当作安装方式。
