# 网页二维码识别

这是一个给 [暴力猴（Violentmonkey）](https://violentmonkey.github.io/) 用的浏览器脚本。网页上出现二维码图片时，在图片上单击鼠标右键，选择「识别二维码」，就能看到里面的文字。如果内容是网址，可以直接打开；也可以一键复制。

识别在你自己的浏览器里完成，不需要把图片上传到别的服务器，也不需要编译。

## 安装前准备

先安装暴力猴扩展。在 Chrome、Edge 或 Firefox 的扩展商店里搜索 **Violentmonkey** 或 **暴力猴**，安装后固定到工具栏即可。

## 安装这个脚本

安装地址（合并到 `main` 分支后，一直用这个链接。脚本也会按这个地址检查更新）：

<https://raw.githubusercontent.com/1275389313/open_qrcode/main/qrcode-reader.user.js>

操作步骤：

1. 用已经装好暴力猴的浏览器打开上面的链接。
2. 暴力猴会弹出安装确认，点 **安装** 或 **确认**。
3. 如果页面只是显示一大段代码，没有弹出安装框：复制地址栏里的网址，打开暴力猴面板，点 **+**，选择「从网址安装」，把网址粘贴进去。

请安装以 `.user.js` 结尾的 Raw（原始文件）地址。GitHub 上普通的代码预览页不能用来安装。

如果上面的固定链接暂时打不开（例如改动还在其他分支里），可以打开本仓库的 `qrcode-reader.user.js`，点击 **Raw**，用打开后的地址安装。

## 怎么用

主要操作是右键：

1. 打开带有二维码图片的网页，等图片显示出来。
2. 把鼠标放在二维码图片上，单击 **右键**。
3. 在弹出的菜单里点 **识别二维码**。
4. 结果窗口会显示识别到的文字。
   - 点 **复制**，把内容复制到剪贴板。
   - 如果内容本身是 `http://` 或 `https://` 网址，还会出现 **打开链接**，点一下就在新标签页打开。

这个右键菜单出现在这些东西上：普通图片（`<img>`）、画布（`<canvas>`）、视频当前画面、用 CSS 背景显示的图片，以及页面里足够大的 SVG 图。菜单只在你右键这些图片时出现，右键普通文字时仍是浏览器原来的菜单。

不想挡住原来的浏览器菜单时，按住 **Shift** 再右键，这次会使用浏览器原来的菜单（保存图片、复制图片等）。

其他入口：

- 页面右下角有一个小按钮，点一下会扫描当前页面上较大的图片。鼠标放到按钮上时，可以点 **×** 把它隐藏到本次刷新为止。
- 按 **Alt+Q**：鼠标正下方如果是图片，就识别这一张；否则扫描整个页面。正在输入文字时不会触发。
- 暴力猴脚本菜单里也有「扫描页面二维码」。

图片特别多时，整页扫描最多检查大约 30 张，并且优先看屏幕里看得到的。想扫某一张时，直接右键那一张更准确，也会看得更仔细。

## 识别不到时

- 确认暴力猴里这个脚本是开启的，并且页面已经刷新过。
- 二维码要大致完整、不要太模糊。太小的图标（大约 30 像素以下）不会弹出菜单，避免妨碍平时浏览。
- 有些网站禁止读取图片像素。脚本会试着重新下载图片再识别；如果仍失败，窗口里会用中文说明原因。
- 一张图里如果挤了好几个二维码，可能只识别出其中一个。可以把另一个单独截出来再试。
- 普通条形码不是二维码，这个脚本不识别。

## 隐私

只有在你点击「识别二维码」、右下角按钮、Alt+Q 或暴力猴菜单之后，脚本才会开始看图片。它不会在后台不停扫描。

跨站图片如果直接读不出来，脚本会用暴力猴的网络权限把这张图片下载到本地再识别。图片和识别结果不会上传到本仓库或别的服务器。

## 脚本是怎么识别的

识别库是 [jsQR](https://github.com/cozmo/jsQR) 1.4.0（Apache-2.0 许可证）。它写在 `qrcode-reader.user.js` 开头的 `@require` 里，安装脚本时由暴力猴下载，不需要在自己电脑上编译或打包。

以后如果要换版本，只需要改这一行网址里的版本号，例如把 `jsqr@1.4.0` 换成新的版本，然后在暴力猴里对本脚本检查更新。

## 更新脚本

暴力猴会定期根据脚本里的地址检查更新。你也可以打开暴力猴面板，找到「网页二维码识别」，手动检查更新。
